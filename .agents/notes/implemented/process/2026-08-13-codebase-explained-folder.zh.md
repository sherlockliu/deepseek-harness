# Agent Note: 图解优先的代码库讲解文件夹

Status: implemented

[English](2026-08-13-codebase-explained-folder.md) | 中文

## Problem

`docs/architecture.md` 是为已经了解 Cordis 的贡献者准备的路线图，而文档语料库通过门槛限制了篇幅、层级、一事一处和双语配对。想以教程方式、图解优先地通读整个代码库的新人，没有一个能承载这种细节量又不触发这些门槛的入口。

## Decision

仓库根目录的 `codebase-explained/` 存放十四个图解优先的 Markdown 页面，讲解架构与代码：插件主干、组合与启动、代理循环、会话日志、作用域与工具、能力接缝、事件系统、LLM 层、Web/API/RPC 界面、会话配套、单仓库构建，以及一次端到端请求追踪。图表使用 Mermaid，并经过与 `scripts/verify-mermaid.ts` 相同的解析器校验（全部块可解析）；正文以 `file:line` 引用源码。该文件夹位于文档语料库之外：没有门槛扫描它，不要求双语副本或字数预算——其索引页命名为 `index.md` 而非 `README.md`，因此不会被 README 工件双语规则捕获——`docs/` 仍是事实的唯一权威归宿。各页面链接回 `docs/` 以获得权威依据，并声明当事实发生偏移时，源码与 `docs/` 优先于讲解文件夹。

## Alternatives considered

**把页面放进 `docs/`。** 语料库会强制要求教程/参考分类、字数预算、一事一处的迁移，以及每页的双语配对；讲解内容有意用图表复述事实，而层级规则禁止这样做。作为入门辅助却要承担持续维护成本，故被否决。

**把页面放进 `.agents/notes/`。** Agent Note 是具有固定格式和生命周期的决策记录，不是教学材料。被否决。

**不把讲解内容放进仓库。** 讲解内容是为提交并接受评审而写的；通过 PR 可以让维护者纠正它，或者整体删除它。被否决。

## Consequences

- 新增一个顶级文件夹，维护者可以维护其准确性，也可以删除它；因为没有门槛覆盖它，其中的链接与图表只与最近一次撰写和评审时一样正确。
- 入门变得图解优先：无需事先了解 Cordis，一个文件夹即可通读整个系统。
- 仓库根目录的表面略增；该文件夹的索引页声明了其非权威的定位。
